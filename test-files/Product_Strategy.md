# Product Strategy & Roadmap — Q4 2026

## Vision
Build the most intuitive document conversion platform for Indian businesses and global users.

## Objectives
1. Ship AI-powered template suggestions using Groq LLM
2. Launch enterprise tier with SSO and team management
3. Achieve 100K monthly active users by December 2026

## Key Deliverables
- **Clean UI**: Obvious options, high contrast typography, instant feedback
- **Accurate Previews**: Real-time rendering with page counts and exact file sizes
- **Direct Downloads**: One-click export with customizable output naming
- **Smart AI**: Document analysis, quality scoring, template suggestions

### Q4 Milestones
- October: Launch AI template engine
- November: Enterprise beta program
- December: 100K MAU milestone

## Technical Roadmap
- Migrate to edge functions for faster conversion
- Implement server-side PDF rendering for complex documents
- Add OCR support for scanned documents
- Build API rate limiting and usage analytics

## Risk Assessment
- Competition from established players (Smallpdf, iLovePDF)
- Need to maintain conversion quality at scale
- AI cost management (Groq free tier limits)
